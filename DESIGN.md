# Asker Marketi Yönetim — Round 4

Mode: Operate. Inventory, dispatch, sales and ledger tasks in daylight and on phones.
Warm canvas #F5F3EE, white surfaces, ink #17201A, secondary #5B6358, rules #E6E2D8.
Olive brand #1F3A2B, selection #E4EDE3, attention #C8892B, danger #B3261E, success #2E7D4F.
Self hosted Manrope with Turkish subset; tabular numerals. Body 16, labels 14, minimum 13; titles 28/34, sections 19/21, KPI 40/48.
8px rhythm; mobile gutters 20px, desktop 40px; content max 1120px. White list surfaces use separators, no nested cards, 14px outer radius and no shadows.
Desktop olive sidebar. Mobile <=900px: compact profile header and fixed five item bottom navigation, overflow through Daha fazla. No hamburger or breadcrumb.
Role selection remembers the choice. Profile contains role switching and the demo explanation. Four distinct Today screens prioritize collecting, retail sale, collection and managerial exceptions.
Picking renders one photographed product at a time, preserving partial quantities and staff notes. Mobile forms are one column with persistent dialog footer.
Lucide line icons, visible amber focus, 180ms opacity/position feedback, reduced motion supported.
Browser verification runs in GitHub Actions because the local Windows IPC sandbox blocks Playwright workers. Measured results, runtime text and live screenshots are recorded in demo-kanit/round4; DESIGN.md describes the system and is not a test report.
