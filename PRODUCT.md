# Asker Marketi Yönetim
## Platform
web, mobile PWA
## Stack
Kullanıcı React + TypeScript + Vite veya uygun sağlam yolu yetkilendirdi. IndexedDB; GitHub Pages.
## Users
Yönetici, depo personeli, mağaza personeli ve muhasebe. Telefonla barkodsuz stok ve sipariş toplama.
## Purpose
Birinci aşama ERP demosu: merkez stok, altı kanal eşleştirme/fiyat, set reçeteleri, sipariş, sevkiyat, cari, personel ve yönetim.
## Constraints
Gerçek ürünler ve anonim sipariş sayımları dört kanaldan salt okuma API bağlantısıyla alınır. İkas token ve GraphQL query POST serbest; mutation yasaktır. Gerçek sipariş tutarları public snapshot ve build içinde bulunmaz. Kişiler ve yerel operasyonlar kurgusaldır. Fatura/bot kapsam dışındadır. Onay beklemeden tamamla ve yayınla.
